## 技术栈

- **前端**：Vue 3（JavaScript）+ Vite + Vue Router
- **后端**：Spring Boot
- **数据库**：MySQL
- **桌面端**：Electron(计划)
- **实时通信**：WebSocket / WebRTC(计划)
- **部署**：
  - Linux / WSL
  - Nginx（反向代理 + 静态资源）
  - Cloudflare Tunnel（对外暴露）
  - Docker Compose（编排所有服务）
