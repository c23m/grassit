# 登录页（Login.vue）的布局

页面挂在 `BaseLayout` 下面，顶部 `NavBar`、底部 `Footer` 都由它提供，本页不再自己套布局。

登录方式有多种，当前只做「用户名 + 密码」这一种。

## 表单布局

```
        h2 登录（居中）

        用户名
        [ 输入框 ]

        密码
        [ 输入框 ]

        [ 提交 ]
        错误信息（有则显示）

      ────── 分隔线 ──────

        其他登录方式 | 另一种登录方式
```

结构对应 [Login.vue](../../frontend/src/views/Login.vue)：

- `section.login`——整页容器
- `h2`——标题
- `form`——提交用 `@submit.prevent`（在输入框里按回车也能提交）
- 两个 `fieldset`——各放一组 `label for` + `TextInput id`，点标签能聚焦输入框
- `Button type="submit"`——提交按钮（`Button` 组件默认是 `type="button"`，不写就不提交）
- 错误提示位——有错误才渲染
- `hr` + 一行占位链接——其他登录方式

## 备注

- 其他登录方式暂时只做占位：外观像链接，但不可点击。用**不带 `href` 的 `<a>`**（HTML 规定的占位链接：不跳转、也不进 Tab 顺序），比写一个假的 `href="#"` 干净。实际可能是邮箱和 GitHub。
- 标签与输入框在结构上是同级元素，上下排还是左右排由样式决定；若选左右排，要保证两个输入框的左边缘对齐。
