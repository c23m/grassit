### 项目经历

**Grassit · 个人博客 / Wiki 系统**（个人项目 · 全栈 · 进行中 · 2026.09 – 至今）

- **项目描述**：面向个人的博客与知识库系统，前后端分离，按版本里程碑推进（当前 0.0.4）
- **技术栈**：FastAPI + 异步 SQLAlchemy + MySQL（asyncmy）+ PyJWT + argon2 ｜ Vue 3 + Vite + Pinia + Vue Router + Axios ｜ Docker Compose
- **我的工作**：
  1. 后端按 `models` / `routers` / `schemas` 分层，用异步 SQLAlchemy 建 `users` 表并落库：注册接口做用户名与邮箱查重（409）、`IntegrityError` 兜底回滚、字段规则校验（422）
  2. 用 JWT（HS256、15 分钟）实现无状态鉴权，`get_current_user` 依赖负责解析 token 并查库，`/users/me` 返回真实用户；密码用 argon2 哈希，用户名不存在与密码错误返回同一条消息（不泄露账号是否存在）
  3. 前端用 Vue 3 + Vite 搭页面骨架，Pinia 管登录态（token 持久化 + 应用启动时恢复），登录 / 注册页做字段校验，把 409 / 422 转成中文提示
  4. 用 Docker Compose 起 MySQL + 后端 + 前端三容器本地环境
- **AI 协同开发实践**（本版差异化）：
  1. 用一份 `AGENTS.md` 作为唯一协作规范（代码风格、异步红线、文档职责、提交约定、改动分级确认），让 AI 与人都按同一套规则干活
  2. 文档先行：`docs/` 分层放规范、任务指南与速查笔记，`docs/todo.md` 管版本与验收标准，`HANDOVER.md` 管状态交接；规范里写死"结论以代码与实测为准"
  3. 关键代码自己写、重复性工作交给 AI；每次改动按重要性分级确认，接口用 curl 与浏览器实测验收；并用 AI 工具排查线上/运行期 Bug

> 面试可展开的细节（都来自代码）：argon2 同步哈希与事件循环的关系（当前仍直接写在 `async def` 里，属已知待改项，被问到就照实说）、JWT 与 refresh token 的分工、`fetchMe` 的并发合并与 401 处理、Pinia 解构丢响应性的坑。
